# 🐳 [실습 2] Nginx 웹서버 실행과 포트 포워딩

교재: `Cloud_컨테이너 이해 및 앱 컨테이너화 실습_2608.pdf` (5쪽)

---

## 📌 1. 핵심 명령어 4단계

```bash
# 1. Nginx 웹서버 백그라운드 실행 및 포트 8080 연결
docker run -d -p 8080:80 --name web nginx

# 2. 실행 상태 확인
docker ps

# 3. 실시간 접속 로그 확인
docker logs web

# 4. 컨테이너 중지 및 삭제
docker rm -f web
```

---

## 🔍 2. 옵션별 비전공자 맞춤 해설

* **`nginx`**: 전 세계에서 가장 널리 쓰이는 무료 고성능 웹서버 프로그램입니다.
* **`-d` (Detach)**: 
  * "터미널 창을 가로채지 말고, 컴퓨터 백그라운드 뒤편에서 조용히 24시간 계속 돌려줘!"
* **`-p 8080:80` (Port Forwarding)**:
  * **`8080` (앞부분)**: 내 Mac 컴퓨터의 외부 포트 번호
  * **`80` (뒷부분)**: Nginx 컨테이너 내부의 기본 웹 포트 번호
  * "내 Mac에서 `http://localhost:8080`으로 접속하면 컨테이너 안 80번 문으로 통과시켜줘!"
* **`--name web`**: 컨테이너의 이름을 `web`으로 깔끔하게 지정합니다.

---

## 🚪 3. [핵심 실험] `-p` 옵션을 빼면 왜 브라우저에서 안 열릴까?

컨테이너는 바깥세상과 철저히 격리된 **"독립된 방"**입니다.
방 안에서 Nginx가 80번 문을 활짝 열고 기다려도, **내 Mac과 연결되는 외부 창문(`-p`)**을 뚫어주지 않으면 바깥에서는 접근할 수 없습니다.
