Jargon Translator & Flow

비전공자를 위한 외계어 IT 용어 번역기

패킷, 포트포워딩, 리버스 프록시 등 전공자들만 쓰던 어려운 단어들을 식당, 아파트, 택배 일상 비유로 쉽고 직관적으로 번역해 드립니다!

어려운 IT 외계어 일상생활 & 식당/택배 비유 진짜 의미 (한 줄 요약)
📦 패킷 (Packet) 우체국 택배 상자: 보내는 사람 주소(IP)와 받는 사람 주소가 적힌 작은 데이터 알갱이 인터넷으로 주고받는 데이터의 기본 배송 단위
🔌 포트 (Port) 아파트 동/호수 (인터폰 번호): 한 컴퓨터 안에 80호(웹), 8080호(WAS), 5432호(DB)가 따로 있음 한 컴퓨터 안에서 여러 프로그램을 구분하는 고유 번호
🔄 포트 포워딩 (-p) 아파트 인터폰 텔레포트: 밖에서 8088 인터폰을 누르면 컨테이너 안쪽 80번 문으로 손님을 연결해 줌 호스트 머신으로 온 요청을 컨테이너 내부로 토스하기
🤵 리버스 프록시 (Reverse Proxy) 고급 레스토랑의 지배인/문지기: 손님이 주방에 직접 못 들어가게 막고, 지배인(Nginx)이 주문을 받아 주방에 전달 보안을 위해 Nginx가 요청을 대신 받아 WAS에 넘겨주는 것
📖 도커 내부 DNS (127.0.0.11) 스마트폰 연락처 (전화번호부): 외우기 힘든 숫자 IP(172.20.0.3) 대신 'was', 'db' 이름만 눌러도 자동 전화 연결 IP 대신 컨테이너 이름만 부르면 알아서 연결해 주는 시스템
☕ Spring Data JPA 주방 보조 요리사 (자동 번역기): 복잡한 SQL 대신 자바 코드로 "회원 목록 꺼내줘"하면 알아서 DB에서 찾아옴 자바 프로그램이 DB와 쉽게 대화하도록 돕는 도구
💾 볼륨 마운트 (-v) 외장 세이브 메모리카드: 게임기 본체를 부숴도 세이브 팩은 내 주머니에 안전하게 보관 컨테이너가 지워져도 DB 데이터는 내 PC에 영구 보존
