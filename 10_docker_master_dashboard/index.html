비전공자의 시선에서 도커의 5대 핵심(프로세스 격리, 가상 네트워크, 볼륨 영속화, 컴포즈 오케스트레이션, 이미지 다이어트)을 스텝 바이 스텝 퀘스트로 클리어합니다!

레지스트리: harbor.skala-gj.com/skala-gj4/skala-webserver-g124
리포지토리: rntqkdl/Cloud_docker_test

3-Tier 상용 웹 아키텍처 데이터 흐름도

Nginx(웹) ➔ Node.js(WAS) ➔ MariaDB(DB) ➔ Docker Volume(스토리지) 전체 경로

1. Web (Nginx:80)

유일하게 외부 포트(80) 개방. 손님을 맞이하고 정적 파일을 서빙하며, 비즈니스 요청은 내부 사설망의 WAS로 안전하게 전달(Reverse Proxy)합니다.

2. WAS (Node.js:8080)

외부 포트 미개방 (보안 격리). 오직 3tier-net 안에서만 통신하며, 회원가입·조회·주문 연산 로직을 실행합니다.

3. DB (MariaDB & Volume)

외부 노출 차단 + 볼륨 마운트. 해킹을 원천 차단하고, 컨테이너가 폭파되어도 mariadb-data 외장 메모리카드로 데이터를 영구 보존합니다.
