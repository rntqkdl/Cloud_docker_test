비전공자 맞춤 일상 & 게임 비유 8선
🎮 ↔ 📺
1. 이미지 vs 컨테이너

이미지: 절대 안 변하는 게임 팩(ROM).
컨테이너: 전원을 켜서 실제 플레이 중인 게임 화면(Process).

💾
2. 볼륨 (Volume, -v)

메모리 카드: 본체 전원을 끄고 게임 팩을 뽑아도 내 레벨과 아이템은 영구 보존됩니다.

🔌
3. 포트 포워딩 (-p)

패드 연결 단자: -p 8080:80은 본체 1번 단자에 조이스틱을 꽂아 80번 방을 조작하는 통로입니다.

👥
4. 스케일아웃 (--scale was=3)

3인 파티 레이드: 1명이 쓰러져도 나머지 2명이 보스를 계속 공격하여 무중단 클리어!

STAGE 1 ~ 9 실습 퀘스트 공략
STAGE 01 첫 캐릭터 소환과 생명주기 (hello-world)
💡 쉬운 비유: 1회성 튜토리얼 몬스터를 소환해서 대사를 듣고 나면 스스로 사라지는 원리!
docker run hello-world docker ps -a # Exited (0) 정상 완료 확인
STAGE 04 영구 세이브 메모리카드(볼륨) 장착 실습
💡 쉬운 비유: 게임기를 부숴도(docker rm -f) 메모리카드(볼륨)만 꽂으면 데이터 100% 부활!
docker volume create mariadb-data docker run -d --name mariadb -v mariadb-data:/var/lib/mysql -p 3306:3306 mariadb:11 # 컨테이너 삭제 후 다시 띄워도 alice, bob, carol 생존 확인!
STAGE 05 Harbor 클라우드 창고에 내 이름표 달아 업로드
💡 쉬운 비유: 내가 만든 커스텀 팩을 전 세계 유저가 다운받을 수 있는 중앙 서버에 등록하기!
docker tag skala-webserver:1.0.0 harbor.skala-gj.com/skala-gj4/skala-webserver-g124:1.0.0 docker push harbor.skala-gj.com/skala-gj4/skala-webserver-g124:1.0.0
STAGE 07 Docker Compose - 3인 파티 원클릭 결성
💡 쉬운 비유: 계약서(compose.yaml) 한 장으로 기사, 마법사, 힐러를 1초 만에 동시 소환!
docker compose up -d # 3-Tier 전체 자동 소환 docker compose ps # 파티원 체력(healthy) 확인 docker compose down -v # 파티 해산 및 초기화
STAGE 08 분신술(Scale=3)과 무중단 방어막 (HA Failover)
💡 쉬운 비유: 공격수 1명이 기절해도 Nginx가 즉시 다른 공격수로 넘겨 손님이 렉을 못 느낌!
docker compose up -d --scale was=3 docker stop 08_scale_and_loadbalancing-was-2 # 1대 고의 종료 curl -s localhost/whoami # 끊김 없이 200 OK!
STAGE 09 멀티스테이지 다이어트 (1.78GB → 185MB)
💡 쉬운 비유: 게임 개발 툴(수십 GB)은 버리고 오직 롬팩에 최종 카트리지(185MB)만 압축해 담기!
# Dockerfile (Multi-Stage) FROM node:18-alpine AS builder WORKDIR /app COPY package*.json ./ RUN npm install --omit=dev FROM node:18-alpine COPY --from=builder /app/node_modules ./node_modules COPY server.js . CMD ["node", "server.js"] # 185MB 극강 압축 달성!
