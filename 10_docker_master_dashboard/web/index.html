≡ 현재 동작 중인 실시간 3-TIER 아키텍처

1. Web (Nginx:80)

유일하게 외부 포트(8088:80) 개방. Vue SPA 정적 화면을 서빙하며, /api/ 요청은 내부 사설망의 Node.js WAS로 안전하게 리버스 프록시합니다.

2. WAS (Node.js:8080)

외부 포트 미개방 (보안 격리). 퀘스트 진척도 저장, 방명록 CRUD, MariaDB 핑 연산을 수행하며 현재 컨테이너 호스트명({{ wasContainer }})을 반환합니다.

3. DB (MariaDB 11)

영구 볼륨(dashboard-db-data) 마운트. 컨테이너가 폭파되어도 내가 완료한 퀘스트 별점과 작성한 공부 메모가 영구 보존됩니다.

CS Engine Architecture

리눅스 커널 가상화 격리 & 런타임 스택

도커 컨테이너가 어떻게 무거운 OS 부팅 없이 0.1초 만에 안전하게 격리된 방을 만드는지 원리를 파헤칩니다.

구분 리눅스 커널 핵심 기술 실제 동작 원리 미적용 시 발생 위험
시야 격리 Namespace PID(프로세스), NET(네트워크 veth), MNT(마운트), UTS(호스트명), IPC, USER를 완전 독립시킴 다른 컨테이너의 프로세스를 강제 종료하거나 패킷 탈취
자원 통제 cgroups v2 CPU 사용률 상한선, RAM 최대 메모리 한도를 지정하고 초과 시 OOM Killer로 통제 하나의 컨테이너 메모리 누수로 호스트 서버 전체 다운
계층 스토리지 OverlayFS (CoW) 읽기 전용 이미지 레이어(LowerDir) 위에 얇은 쓰기 층(UpperDir)을 얹어 변경분만 기록 컨테이너 생성마다 수 GB의 OS 파일 전체 복사 낭비
